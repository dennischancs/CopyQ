## 状态图

```
todo -> doing -> review -> verified

any -> dropped
```

## 原子性自查

每个任务在 `doing` 之前确认四条：

1. 单次会话内可完成。T4 和 T6 如果一次做不完，先拆任务再改状态，不要一边写一边把范围加进 SPEC。
2. 有单一明确的验收判据。
3. 可独立提交而不破坏桌面 `testConfigSync`。
4. 依赖关系已写在表里。
