## 难做

留下，是为了避免以后有人把「没做」写成「做不到所以删掉需求」。它们仍然不是首次的缺口。

| # | 事项 | 为什么难，以及为什么不能假装做完 |
|---|------|--------------------------------|
| H1 | 后台一直监听剪贴板 | Android 10 之后普通应用不能在后台持续读剪贴板。iOS 不把剪贴板流给第三方应用。禁止用辅助功能或私有接口绕过 |
| H2 | 全局快捷键 | 手机没有电脑那种系统级热键。Qxt 只覆盖桌面 |
| H3 | 托盘菜单 | 没有桌面托盘。通知栏不是 CopyQ 的托盘命令 |
| H4 | 按来源窗口忽略 | 第三方应用拿不到可查询的前台窗口标题 |
| H5 | 把内容粘进上一个应用 | 不能向其他应用注入按键 |
| H6 | 常驻本地服务器和命令行 | 系统会杀掉后台进程。手机沙箱里也没有电脑那套客户端用法 |
| H7 | FakeVim | 依赖桌面编辑器和键盘模型 |
| H8 | 目录同步 | 桌面插件假设的是电脑文件系统，不是手机沙箱 |
| H9 | 开机自启 | 现有实现绑在桌面平台。手机上即使有近似能力，也不是同一个开关 |
| H10 | GnuPG / QCA 钥匙 | 这次桌面构建没有打开 QCA。手机钥匙链是另一套接口 |
| H11 | 历史也走 WebDAV | 和当前配置包的排除规则相反。要做就必须新开规格，不能塞进现有 zip |
| H12 | 合并 `upstream/android` 当作移植完成 | 那个分支没有后台剪贴板，也没有这次的 WebDAV。接口还是旧的 |
